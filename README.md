# 🍩 FOFFU — Landing Page de Donuts

Landing page de portfólio para venda de donuts, com foco em apresentação visual e identidade de marca.

🌐 **Demo:** [foffu.vercel.app](https://foffu.vercel.app)

## 🎯 O que é

Site institucional / portfólio para uma marca fictícia de donuts artesanais. Estrutura focada em:

- Apresentação visual da marca
- Catálogo de produtos
- Layout responsivo
- Identidade visual consistente

## 🛠️ Stack

- **HTML5** — estrutura semântica
- **CSS3** — design e responsividade
- **Vercel** — deploy

## 🚀 Como rodar localmente

```bash
git clone https://github.com/kahuasantos1-ui/FOFFU.git
cd FOFFU
# abrir index.html no navegador (ou usar Live Server no VSCode)
```
